# 阶段规划与执行

Astra/当前 LLM 根据实际 RGB-D、机器人和夹爪反馈确定阶段目标，Jev 在可用阶段动作中选择下一步。`decision.py` 验证回答与当前状态的对应关系，`policy.py` 决定可执行还是交回 LLM，`teacher_targets.py` 和 `whole_task_collection.py` 记录实际下发动作及反馈。

路线由当前杯位、桌面和固定工具姿态计算，执行前核对 IK/FK 与原生设备状态。夹持、抬升、放回和松开分别根据真实反馈结束；完整轨迹的成功由用户确认。

`cases/` 保存两次用户验收及一次中断恢复案例。案例用于提出和筛选阶段动作，每次执行使用当前观测与任务范围。夹爪几何与相机标定见 [硬件资料](../../hardware/README.md)，阶段决策与实机结果见 [结果索引](../results/README.md)。

## 已知问题

现有案例来自同一杯子和工作区，尚无跨场景成功率。Jev 的概率阈值没有完成统计校准。
